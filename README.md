# snap-streak-tracker

## Project Goal
Snapchat users often stress about losing their hard-earned daily streaks because they forget to send a snap before the timer runs out. This project is a smart tracker and notification assistant that monitors streak countdowns and helps friends stay connected without the anxiety of losing their records.

## MVP Scope (Minimum Viable Product)
- Friend username and streak count list input.
- Daily counter update command (+1 to streak).
- Expiration warning alerts.

## Future Plans (Schedule Quadrant)
- Auto-notification push reminders.
- Streak leaderboard ranking.
- Streak recovery tracker.

## Tech Stack
- **Language:** Java
- **Libraries:** Standard Java libraries (`java.util.Scanner`, `java.time.LocalDate`)
- **Data Storage:** Plain text/CSV file saving
